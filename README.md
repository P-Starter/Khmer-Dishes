# 🍳 Khmer Dishes — Cambodian Recipe Catalog

An open, **bilingual** (English + ខ្មែរ) structured catalog of **1,059+ Cambodian
(Khmer) dishes** — each with a trilingual name (Khmer / romanized / English),
structured ingredients, and step-by-step *how-to-cook* instructions — plus a
lightweight, searchable webview that runs anywhere as a static site.

> **Live site:** https://p-starter.github.io/Khmer-Dishes/

The goal is to grow into the most complete, machine-readable reference of Khmer
home cooking — and to recommend a **daily Khmer dish** to anyone learning to cook it.

---

## ✨ Features

- **1,059 dishes** across 14 categories (stir-fry, soup, curry, grilled, fried, braised, steamed, salad, noodles, rice, dip, dessert, drink, snack).
- **Trilingual names** — Khmer script · romanization · English.
- **Bilingual content** (EN + ខ្មែរ) — Khmer translations of descriptions, cooking steps + chef's tips, ingredient items and notes, equipment, and section titles. Native readers can follow the recipe end-to-end in Khmer.
- **Real cooking steps** — grouped ingredients + numbered instructions with chef's tips.
- **Searchable webview** — typo-tolerant fuzzy search, filters (category / protein / diet / spice), a deterministic **dish of the day**, and a **full-screen recipe dialog** on big screens (sticky ingredients sidebar + roomy method area).
- **Open data** — one clean JSON file validated by a published [JSON Schema](#-data--schema).
- **Zero backend** — pure static files; deploys free on GitHub Pages.

## 📦 Repository structure

| File | Purpose |
|------|---------|
| `index.html` | Self-contained webview (search, filters, dish-of-the-day, bilingual recipe detail). |
| `khmer_menu.json` | **The dataset** — `{ meta, recipes[] }`, 1,059 dishes. |
| `khmer_menu.schema.json` | JSON Schema (draft-07) — the data contract. |
| `khmer_data.js` | The dataset wrapped as `window.KHMER_MENU` so the page works offline by double-click. |
| `generate_khmer_menu.py` | Generator — the **source of truth** for the catalog (including all Khmer translations). |
| `fetch_images.py` | Optional: fetch one stock photo per dish from Pexels / Unsplash, gated for Khmer-relevance. |
| `images/dishes/` | Per-dish photos (`<slug>.jpg`) plus `attribution.json`. Missing photos render as the placeholder. |
| `credits.html` | Auto-generated photo credits (regenerated by `fetch_images.py`). |
| `.nojekyll` | Marker so GitHub Pages serves the static assets as-is. |

## 🧾 Data & schema

The catalog is a single JSON document validated against
[`khmer_menu.schema.json`](./khmer_menu.schema.json). Use it as a dataset or a
read-only API — point your app straight at `khmer_menu.json`.

```jsonc
{
  "meta": {
    "schemaVersion": "1.0",
    "cuisine": "Khmer",
    "count": 1059,
    "categories": ["stir-fry", "soup", "curry", "..."],
    "language": { "primary": "en", "names": ["km", "romanized", "en"] }
  },
  "recipes": [ /* … */ ]
}
```

### Recipe object

```jsonc
{
  "id": "khm-0001",                       // stable unique id
  "slug": "fish-amok",                    // URL-safe slug
  "name": { "km": "អាម៉ុកត្រី", "romanized": "Amok Trey", "en": "Fish Amok" },
  "category": "curry",
  "subcategory": "amok",
  "cuisine": "Khmer",
  "description":   "Cambodia's national dish — a silky steamed coconut fish curry…",
  "descriptionKm": "ម្ហូបជាតិកម្ពុជា — ការីត្រីចំហុយក្នុងស្លឹកចេក…",  // bilingual
  "image": "images/dishes/fish-amok.jpg", // per-dish; falls back to placeholder
  "imageFamily": "fish-amok",             // grouping metadata (kept for contributor handoff)
  "tags": ["signature", "fish", "steamed", "coconut"],
  "dietary": ["pescatarian", "gluten-free"],
  "spiceLevel": 1,                        // 0–5
  "difficulty": "medium",                 // easy | medium | hard
  "servings": 4,
  "time": { "prepMinutes": 40, "cookMinutes": 25, "totalMinutes": 65 },
  "kroeung": ["lemongrass", "galangal", "turmeric", "…"],   // the Khmer flavour base
  "equipment":   ["steamer", "banana leaf cups", "mortar and pestle"],
  "equipmentKm": ["ឆ្នាំងចំហុយ", "ពែងស្លឹកចេក", "អង្គ្រែ"], // parallel array
  "ingredients": [
    {
      "group": "main",
      "item":    "snakehead fish fillet",  "itemKm":  "សាច់ត្រី",
      "quantity": 500, "unit": "g",
      "notes":   "sliced",                 "notesKm": "ហាន់"
    }
  ],
  "instructions": [
    {
      "step": 1,
      "text":   "Pound the kroeung to a smooth paste.",
      "textKm": "បុកគ្រឿងលឿងឱ្យល្អិតៗ។",
      "tip":    "Smoothness is everything in amok.",
      "tipKm":  "ភាពល្អិតគឺជាគន្លឹះនៃអាម៉ុក។"
    }
  ]
}
```

### Field reference

| Field | Type | Notes |
|-------|------|-------|
| `id` | string | `khm-NNNN`, unique & stable. |
| `slug` | string | URL-safe, unique. |
| `name` | object | `{ km, romanized, en }` — `en` required. |
| `category` / `subcategory` | string | Menu category + Khmer technique family (`cha`, `samlor`, `amok`, `kho`, …). |
| `description` / `descriptionKm` | string | English + optional Khmer paragraph. |
| `image` / `imageFamily` | string | Per-dish photo path + grouping metadata. Missing photos render the placeholder. |
| `tags` / `dietary` | string[] | `dietary` ∈ `vegetarian, vegan, pescatarian, gluten-free, dairy-free, halal`. |
| `spiceLevel` | int 0–5 | 0 = none, 5 = very hot. |
| `difficulty` | enum | `easy` \| `medium` \| `hard`. |
| `servings` | int | — |
| `time` | object | `prepMinutes`, `cookMinutes`, `totalMinutes`. |
| `kroeung` | string[] | Aromatic paste components. |
| `equipment` / `equipmentKm` | string[] | Tools + optional parallel Khmer array (same length). |
| `ingredients[]` | object[] | `{ group, item, itemKm?, quantity?, unit?, notes?, notesKm? }`. |
| `instructions[]` | object[] | `{ step, text, textKm?, tip?, tipKm? }`. |

### Bilingual coverage today

| Field | EN | ខ្មែរ |
|---|---|---|
| Trilingual names (`name.km` / `romanized` / `en`) | 100% | 100% |
| Recipe description | 100% | **100%** |
| Cooking step text | 100% | ~47% (the common cross-recipe phrases) |
| Iconic dishes (description + every step + every tip) | 5 / 5 | **5 / 5** |
| Ingredient item names | 100% | **~99%** |
| Ingredient prep/notes | 100% | ~87% |

Coverage was authored by hand for the high-leverage items; remaining gaps live
in style-specific sentences and uncommon ingredients, and are great
first-contribution targets (see [Contributing](#-contributing--submit-more-dishes)).

## 🔁 Regenerating the catalog

`khmer_menu.json` and `khmer_data.js` are **build artifacts** — the source of
truth is `generate_khmer_menu.py`. It composes dishes from authentic Khmer
building blocks (`cooking method × aromatic/vegetable style × protein`) plus
hand-written iconic dishes. Output is deterministic.

```bash
python generate_khmer_menu.py     # rewrites khmer_menu.json + khmer_data.js
```

## 🖼️ Dish images (optional)

Each dish gets **its own image slot** at `images/dishes/<slug>.jpg`, fetched one
at a time so protein variants aren't forced to share a misleading photo. A photo
is only kept if its alt-text or page URL contains a clearly Cambodian/Khmer term
(`cambodian`, `khmer`, `amok`, `lok lak`, `kuy teav`, `prahok`, `samlor`,
`kreung`, …). Otherwise the dish keeps the emoji placeholder — **better an honest
placeholder than a wrong photo**.

```bash
# free API key: https://www.pexels.com/api/  or  https://unsplash.com/developers
python fetch_images.py --dry-run                              # preview per-dish queries
python fetch_images.py --source pexels --key YOUR_KEY --limit 10   # test a few
python fetch_images.py --source pexels --key YOUR_KEY              # full run (resumable)
```

Images land in `images/dishes/`, with attribution written to
`images/dishes/attribution.json` and `credits.html`. Curated queries for iconic
dishes live in `QUERY_OVERRIDES` at the top of `fetch_images.py`; the
Khmer-relevance gate is `KHMER_TERMS` in the same file. Both are easy to extend.

## 🤝 Contributing — submit more dishes

**We want this catalog to grow well beyond 1,000 dishes.** Authentic Khmer
recipes — regional specialties, family recipes, festival dishes, street food —
are all welcome.

Because the JSON is generated, **don't edit `khmer_menu.json` directly** (it gets
overwritten). Instead, add to `generate_khmer_menu.py`:

- **A one-off named dish** → add a record to the `iconic()` function (hand-written, full recipe).
- **A new family of variations** → add an entry to the matching style list, e.g. `CHA_STYLES`, `SAMLOR_STYLES`, `CURRY_STYLES`, `VEG_PAIRS`, `PROTEINS`, the dessert/drink/snack lists, etc. It will be combined across proteins automatically.

Then run `python generate_khmer_menu.py` and commit the updated artifacts.

**Checklist for a good submission**

- [ ] Trilingual name (Khmer script + romanization + English).
- [ ] Correct `category` and a sensible `subcategory`/technique.
- [ ] Authentic `kroeung` / aromatics where relevant.
- [ ] Real, ordered `instructions` a home cook can follow.
- [ ] `ingredients` with quantities and helpful `notes`.
- [ ] `dietary`, `spiceLevel`, and `difficulty` set honestly.
- [ ] Data still validates against the schema.
- [ ] Khmer translations (`descriptionKm`, step `textKm`/`tipKm`, ingredient `itemKm`/`notesKm`) are appreciated but **not required** — if you only contribute English we can fill the Khmer side via the central lookups.

**Extending the Khmer translation layer.** In `generate_khmer_menu.py`, the
finalize section holds the centralized Khmer tables — `KM_DESC_BY_FAMILY`,
`KM_INGREDIENT`, `KM_NOTES`, `KM_EQUIPMENT`, and the regex `PHRASE_RULES`.
Adding a single entry to any of these can cover dozens of recipes at once;
this is one of the most useful contributions.

Open a Pull Request with a short note on the dish and its region/source. 🇰🇭
